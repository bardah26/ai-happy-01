Make the AI judge happy — make.fun bounty entry: a deterministic Python program that paints one cheerful image for the AI judge. A pink "DEAR JUDGE," ribbon, a note, and a three-tier birthday cake with candles, balloons and confetti. It uses only the Python standard library, writes exactly one PNG (768x1024) to /output/output.png, and produces identical bytes on every run.

## Run it

```sh
python main.py
```
